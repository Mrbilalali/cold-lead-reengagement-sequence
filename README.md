# Cold-Lead Reengagement Sequence — Interactive Demo

An interactive, scripted simulation showing how an AI follow-up sequence reactivates a 90-day-old lead.

Pick a fictional cold lead, run the sequence, choose how the lead replies (interested, maybe later, or no reply), and see the AI respond — ending on a reactivated lead booking an appointment in under 90 seconds.

This is a scripted simulation only. It does not place real calls, send real SMS, or make real bookings. All businesses, names, and numbers are fictional (fake 555 numbers).
